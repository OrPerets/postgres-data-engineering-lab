# Instructor guide — MapReduce
Answers: 1) ABR/CCR/ACB → A:2 B:2 C:3 R:2. Changing reducer count changes routing, not key totals. 2) A safe combiner sums intermediate counts; one key must map consistently to a reducer. 3) Mean states are (sum,count), not mean alone. Unequal group sizes make naive mean-of-means incorrect. 4) Population variance can use (n,sum,sum_squares) but is numerically unstable for huge close-valued numbers; stable alternatives use mergeable Welford states. 5) A skewed key creates hot reducer; salting plus two-stage aggregation can redistribute work, at cost of an extra merge. 6) Median-of-medians is generally not the global median. 7) This lab simulates local grouping, not network shuffle.
