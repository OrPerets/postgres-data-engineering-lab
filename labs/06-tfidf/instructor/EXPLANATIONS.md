# Instructor guide — TF-IDF
Use the source lecture's four documents (D1–D4). For data in D1, count=2, len=4, TF=1/2. DF(data)=3, N=4; natural-log IDF=ln(5/4)=0.22314355; TF-IDF=0.11157178. The lecture also presents a log2 convention: log2(5/4)=0.3219281; it gives a different score. Four MapReduce phases: ((term,doc),1) count; (doc,(term,count)) document lengths; (term, doc) distinct DF; score = count/length*IDF. Global DF cannot be computed independently per worker without merging document sets. For new documents, the global N and DF can change and old TF-IDF scores may need recomputation.
